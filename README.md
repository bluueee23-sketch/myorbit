# 나의 궤도 (MY ORBIT)

> 생일만 넣으면, **나를 주인공으로 한 잡지**가 나오는 무료 AI 사주 앱

---

## 0. 사이트 실행하기

추가로 설치할 패키지는 없어요. [Node.js](https://nodejs.org) 18 이상만 있으면 돼요.

### 내 컴퓨터에서 보기

```bash
git clone https://github.com/bluueee23-sketch/myorbit.git
cd myorbit
npm start
```

브라우저에서 http://localhost:3000 을 열면 돼요.

### AI 해석 켜기 (선택)

1. `.env.example` 파일을 복사해서 이름을 `.env` 로 바꿔요.
2. [Anthropic Console](https://console.anthropic.com)에서 API 키를 발급받아 `ANTHROPIC_API_KEY=` 뒤에 붙여 넣어요.
3. 다시 `npm start`

키가 없어도 사이트는 돌아가요. 그때는 일간·오행에 맞춘 **기본 원고**가 나오고, 키를 넣으면 신분·고민까지 반영한 **AI 해석**으로 바뀌어요.

### 인터넷에 올리기 (Vercel, 무료)

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 가입
2. **Add New → Project** 에서 `myorbit` 저장소를 고르고 **Deploy**
3. 프로젝트 **Settings → Environment Variables** 에 `ANTHROPIC_API_KEY` 추가 → 다시 배포

`public/` 폴더가 화면, `api/` 폴더가 서버 기능으로 자동 인식돼요. 이후에는 GitHub에 올릴 때마다 자동으로 다시 배포돼요.

### 폴더 구조

| 위치 | 하는 일 |

### 사주 계산 기준

- 년주·월주: 입춘·절기의 **정확한 시각** 기준
- 일주·시주: 서울 기준 시각 (자시는 23:30~01:30, 23:30부터 다음 날)
- 서머타임(1948~51, 1955~60, 1987~88)과 1954~61년 표준시(UTC+8:30) 자동 보정
- 음력·윤달 입력 지원, 시간 모르면 시주 없이 계산

### 지금 버전에서 아직 안 되는 것

- 메일 실제 발송: `SUBSCRIBE_WEBHOOK_URL` 을 연결하기 전까지는 "준비 중"으로 안내돼요
- 질문하기(ASK), 결제, 다른 고민 기사·궁합·신년운세: 화면에 "곧 열려요"로만 표시
- 화보 사진: 지금은 그림으로 자리만 잡아둠

## 1. 이게 뭐예요?

- 생년월일을 넣으면 내 사주 결과가 **잡지 표지 + 기사**처럼 나옵니다.
- 지금 제일 고민되는 것(이직, 연애, 시험 등)에 대한 답이 기사로 실립니다.
- 결과는 무료, 예쁜 표지는 인스타에 공유하고 싶게 만듭니다.

## 2. 우리가 잘해야 하는 것 (우선순위)

1. **사주 계산이 정확할 것** — 틀리면 끝
2. **"나한테 하는 말" 같은 해석** — 뻔한 운세 말고 내 이야기처럼
3. **공유하고 싶은 표지 디자인**

## 3. 사용 흐름

1. **지금 당신은?** — 직장인 / 취준생 / 수험생 / 대학생 / 그 외
2. **요즘 제일 신경 쓰이는 건?** — 6개 중 1개 선택

   | 신분 | 고민 선택지 |
   |---|---|
   | 직장인 | 이직, 사람, 돈, 번아웃, 연애, 그냥 |
   | 취준생 | 합격, 방향, 면접, 멘탈, 돈, 연애 |
   | 수험생 | 합격운, 집중력, 멘탈, 시험날, 한 번 더?, 그냥 |
   | 대학생 | 진로, 연애, 사람, 휴학, 돈, 그냥 |
   | 그 외 | 일, 돈, 사람, 연애, 컨디션, 그냥 |

3. **언제 태어났나요?** — 이름, 생년월일, 태어난 시간(몰라도 됨), 양력/음력, 성별
4. **결과 보기** — 표지 → 기사

## 4. 결과 화면

**표지**
- 상단에 MY ORBIT 로고
- 내 사주의 핵심 글자를 크게, 별명(예: "흰 원숭이")
- 표지 색은 내 사주에 따라 자동으로 정해짐 (5가지)

**기사 (아래로 스크롤)**
1. 첫 문단 — 나를 한 줄로 소개
2. 내 사주표 (계산 근거 그대로 공개)
3. 나는 어떤 사람인지
4. 내 기운의 균형 (많은 것 / 부족한 것)
5. **내 고민에 대한 답** ← 핵심
6. 부족한 기운 채우는 팁
7. 질문하기
8. 이메일 남기기 (결과 다시 받기 + 매달 운세 받기)

## 5. 돈 버는 구조

**처음엔 공짜로 보여주고, 더 궁금한 건 돈 받고 보여준다.**

| 구분 | 내용 | 가격 |
|---|---|---|
| 무료 | 내 사주 결과 + 고른 고민 1개 답 | 0원 |
| 무료 | 매달 이메일 "이번 달 운세" 짧은 버전 | 0원 |
| 한 번 결제 | 다른 고민 보기 (나머지 5개) | 테스트 예정 |
| 한 번 결제 | 궁합 | 테스트 예정 |
| 한 번 결제 | 2027 신년운세 | 테스트 예정 |
| 월 구독 | 매달 운세 자세한 버전 + 직접 질문 몇 번 | 테스트 예정 |
| 나중에 | 결과 인쇄본, 친구에게 선물하기 | — |

**순서**
1. 지금: 무료 결과 + 다른 고민 보기 + 궁합 + **신년운세** (연말 시즌이라 첫 유료 상품으로 제일 좋음)
2. 사람이 모이면: 월 구독
3. 그 다음: 인쇄, 선물
